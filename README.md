# Jarvis

Personal command-centre dashboard. v1 is a single `index.html`, no install needed.

- Particle orb (tap it)
- Weekly usage meter (manual slider, saves on device)
- Brain-dump notes (saves on device)
- GitHub trending repos this week (live from GitHub's public API)
- Skills panel (placeholders for now)

## Open it

Turn on GitHub Pages: repo Settings > Pages > Deploy from branch > `main` / root.
Your link will be `https://dixkrew-pixel.github.io/Jarvis/`.
